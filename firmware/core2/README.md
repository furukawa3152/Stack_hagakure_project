# Core2 ファームウェア

対象は M5Stack Core2 です。Groki Bot の CoreS3 向けファームウェアは書き込まないでください。

`lcd_touch/` は、画面へ「Core2」「LCD」と出し、タッチ座標をシリアルへ流すスケッチです。マイク、スピーカー、Wi-Fi は無効にしています。

`audio_check/` は、440 Hz を2回鳴らしてからスピーカーを止め、マイクを 16 kHz で1秒測ります。サンプル値は出しません。

`wifi_link/` は、2.4 GHz の Wi-Fi から Gateway へ hello し、マイクを 16 kHz で 2 秒送って、戻った音声をスピーカーで鳴らすスケッチです。マイクとスピーカーは同時に使いません。パスワードとトークンは `secrets.h` に置き、例は `secrets.h.example` です。2026-11-07 に `aterm-fb23d0-g` のチャンネル 11 へ入り、`192.168.0.13` から 100 フレームを送って `echo_match=1` を確認した。01:45 ごろ、利用者にはその再生が聞こえた。

2026-11-07 に M5Stack Arduino コア 3.3.10 と M5Unified 0.3.0 で書き込んだ。シリアルでは基板名 M5StackCore2、電源 AXP192、バッテリー 4133 mV、画面 320x240、`ready` まで確認した。利用者の確認では画面に文字が出ている。タッチは `147,159` と `214,123` をシリアルで確認した。マイクは 16000 サンプルが 960 ms で届いた。01:06 ごろ、440 Hz が2回聞こえたことを利用者が確認した。同じ日、`wifi_link` は 2.4 GHz を3つ見たが、最初の SSID と `aterm-fb23d0-a` は含まれなかった。`aterm-fb23d0-g` のチャンネル 11 には入り、`hello_ack` と `pong` まで確認した。パスワードとトークンはリポジトリに置いていない。ESP-IDF か PlatformIO かは、マイク、スピーカー、画面、Wi-Fi を同時に動かしてから選びます。
